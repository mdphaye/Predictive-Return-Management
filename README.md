# Predictive Return Management System

A lightweight ML-powered app that predicts the likelihood of product returns based on order and delivery details.

### Live Demo
(https://predictive-return-management-eduwdwfmqi4jn3axsdrbaq.streamlit.app/)
### Tech Stack
- Python (Pandas, Scikit-learn)
- Random Forest Classifier
- Streamlit (for interactive dashboard)

### Features
- Upload CSV order data
- Predict return likelihood in real-time
- Visualize distribution of return risks
- Download results as CSV
